# SimpleBankingSystem

CPE262 Console Application Project

## Description

SimpleBankingSystem is a C# console-based banking application that simulates basic banking operations using Object-Oriented Programming (OOP) and CSV file handling. The system supports both bank employees and account holders with different access levels.

---

## Features

- 🔐 Employee Login
- 👤 Account Holder Login
- 📝 User Registration
- 💳 Multiple Account Types
  - Savings
  - Checking
  - ATM
  - Debit
  - Time Deposit
  - Foreign Currency
- 💰 Deposit
- 💸 Withdraw
- 🔍 Search Account
- 📋 View Accounts
- 🗑 Delete Account
- 💾 CSV File Storage

---

## Technologies Used

- C#
- .NET Console Application
- Object-Oriented Programming (OOP)
- CSV File Handling
- Visual Studio 2022
